git-remote-tau(1)
=================

NAME
----
git-remote-tau - Tau-native transport helper for tau:// repositories

SYNOPSIS
--------
[verse]
'git clone' tau://<repository>
'git fetch' <tau-remote>
'git push' <tau-remote> <refspec>

DESCRIPTION
-----------

The Hermes Ark Git fork ships `git-remote-tau`, a remote-helper that makes
`tau://` repositories available to this Git client.

A `tau://` repository is Tau-native.  HTTP(S) and SSH remotes continue to use
Git's normal object database and Git object identifiers.  The `tau://` transport
uses Tau object identities instead: refs point to `tau:<hash>` values, commit
objects point to Tau tree and parent objects, and tree objects point to Tau child
objects.

Git object IDs are bridge-local implementation details used only while the helper
imports from or exports to Git's fast-import/fast-export protocol.  They are not
written to Tau manifests or Tau objects.

TAU OBJECT CODEC
----------------

The object codec is `tau-native-v1`.  Each Tau object is canonical JSON hashed by
SHA-256 over the canonical byte representation.  The resulting hash is the Tau
object identity and storage key.

Blob object::
	Stores file content as base64.  Blobs have no child references.

Tree object::
	Stores entries containing mode, name, child kind, and child object reference.
	The child reference is always `tau:<hash>`.

Commit object::
	Stores `tree`, `parents`, non-identity commit headers, and message.  The tree
	and parent references are always `tau:<hash>`.

Tag object::
	Stores the tagged object as `tau:<hash>`, the tagged object kind, tag headers,
	and message.

This means a reader can walk repository history directly in TauStorage by reading
manifest refs, loading Tau commit objects, following Tau parent/tree references,
and then following Tau tree entries.  No Git SHA-1 lookup table is required or
present in Tau storage.

STORAGE MODES
-------------

Local Tau store
~~~~~~~~~~~~~~~

By default, the local Tau store lives at:

	$HOME/.git-tau/store

For tests or isolated repositories, set `GIT_TAU_STORE`:

	GIT_TAU_STORE=/tmp/tau-store git clone tau://demo

The store contains:

`objects/`::
	Tau-native content-addressed objects.  The path is derived from the Tau object
	hash.

`repos/<name>/cache.git`::
	A local bare Git bridge cache.  This cache exists so regular Git commands can
	interoperate with the Tau-native object graph; it is not the canonical remote
	state.

`repos/<name>/latest.json`::
	The latest Tau-native repository manifest.  Refs in this manifest point to Tau
	object IDs.

TauStorage client API mode
~~~~~~~~~~~~~~~~~~~~~~~~~~

Set `GIT_TAU_DEVNET_MANIFEST` to enable networked TauStorage client mode.  The
helper then calls an Autonomi-compatible client command for every Tau-native
object and manifest:

[listing]
----
ant file upload <tau-object-json> \
	--public \
	--devnet-manifest <manifest> \
	--allow-loopback \
	--evm-network <network>

ant file download <address> -o <output> \
	--devnet-manifest <manifest> \
	--allow-loopback \
	--evm-network <network>
----

Environment variables:

`GIT_TAU_CLIENT`::
	Client executable. Defaults to `ant`.

`GIT_TAU_DEVNET_MANIFEST`::
	Path to the TauStorage/Autonomi devnet manifest. Setting this enables
	TauStorage client API mode.

`GIT_TAU_EVM_NETWORK`::
	EVM network argument for the client. Defaults to `local`.

`GIT_TAU_STORE`::
	Local helper state, manifest pointer files, Tau object cache, and Git bridge
	cache.

In TauStorage client mode, each manifest object entry records the returned
network address:

[listing]
----
"<tau-hash>": {
  "kind": "commit",
  "size": 428,
  "taustorage": { "address": "tau://..." }
}
----

The latest manifest is also uploaded; its returned address is stored locally in:

	$GIT_TAU_STORE/repos/<name>/latest.addr

MANIFEST SHAPE
--------------

A published manifest contains fields like:

[listing]
----
{
  "schema_version": 2,
  "repository": "demo",
  "identity_mode": "tau-native",
  "object_codec": "tau-native-v1",
  "refs": {
    "refs/heads/main": "tau:<commit-tau-hash>"
  },
  "objects": {
    "<commit-tau-hash>": {
      "kind": "commit",
      "size": 428,
      "taustorage": {
        "address": "tau://<network-address>"
      }
    }
  },
  "signing": { "algorithm": null, "signature": null }
}
----

A commit object contains Tau references only:

[listing]
----
{
  "schema_version": 1,
  "codec": "tau-native-v1",
  "kind": "commit",
  "tree": "tau:<tree-tau-hash>",
  "parents": ["tau:<parent-commit-tau-hash>"],
  "headers_b64": ["..."],
  "message_b64": "..."
}
----

A tree object contains Tau references only:

[listing]
----
{
  "schema_version": 1,
  "codec": "tau-native-v1",
  "kind": "tree",
  "entries": [
    {
      "mode": "100644",
      "name_b64": "UkVBRE1FLm1k",
      "kind": "blob",
      "object": "tau:<blob-tau-hash>"
    }
  ]
}
----
